Adventure Game

THE ARCHIVE — a full-stack text adventure

THE ARCHIVE is a full-stack text adventure: React frontend (choices, 18ms typewriter, ambient backgrounds, JWT auth, leaderboard) and Spring Boot backend (38-scene story service, gated choices, achievements, scoring, leaderboard). An Archivist chases the Pale Archivist across 3 chapters.

01 · Overview

Overview

  • Read the scene, pick a choice, unlock items/flags, chase seals and endings.
  • Demonstrates OOP, state machines, auth and client-server flow inside a game, not CRUD.
  • For choice-fiction players and reviewers of game-state logic.
  • Scene graph with gating, score/health deltas, 6 achievements, top-10 leaderboard, protected routing.

02 · The Problem

The Problem

  • Logic, narrative and state tangle when hardcoded in UI.
  • Choices need gating, scoring and endings without breaking the graph.
  • Auth must persist across 38 scenes.

03 · The Solution

The Solution

  • Content as data: GameScene + Choice (nextSceneId, requiresItem/Flag, scoreBonus).
  • Service: validate → check items → score/health → advance → grant items → achievements → track.
  • Client: skip-able typewriter, gating UI, HUD, restart/exit, ending summary.

10 · Challenges & Decisions

Challenges & Decisions

  • Tangle → content-as-data + resolver → story edits avoid UI code.
  • Pacing → gate until done + skip → readable control.
  • Scope → 3 chapters, two victory endings → finishable game.
