Case Study 05

AppleSupport AI

AI Customer Support Agent — Research Pipeline

AppleSupport AI is a support-agent research pipeline on real AppleSupport tweets — not a chatbot demo. Verified phases 1–3: thoughtvector/customer-support-on-twitter loading, reply-graph reconstruction, 10-class taxonomy, baselines, MiniLM classifiers and a 200-row golden set. Retrieval, generation, escalation policy and LLM judging are planned phases 4–9, not implemented.

01 · Overview

Overview

  • Reconstruct real threads, classify needs, evaluate with a blind golden set.
  • Flat tweet rows become reply-graph conversations before modelling.
  • ML research on 2.8M-scale data with AppleSupport focus.
  • Gated steps: validation gates, leakage-free splits, CV-on-train selection.

02 · The Problem

The Problem

  • Raw CSV (tweet_id, author_id, inbound, created_at, text, response ids) is not conversations.
  • Naive splits leak threads across train/test.
  • Keyword models miss paraphrase; agent claims need measured foundations.

03 · The Solution

The Solution

  • Chunked loader (200k chunks, IDs as strings) + thread collection + topic EDA.
  • Reply-graph DFS with pair extraction + 7-point validation gate.
  • 10-class taxonomy; keyword/majority/TF-IDF baselines; frozen MiniLM classifiers; blind 200-row golden set.
