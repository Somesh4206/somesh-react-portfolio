Case Study 01

SkillVision AI

Intelligent Career & Skill Intelligence System

SkillVision is a full-stack AI career copilot and placement platform. The verified build is React 19 + Vite + Tailwind, an Express + TypeScript backend, Google Gemini 2.5 Flash agents, JWT + bcrypt auth, and a file-backed JSON store — deployed at skillvisionai.onrender.com. There is no vector database in this build.

01 · Overview

Overview

  • AI career copilot: upload a resume, get an ATS score (0–100), see skill gaps on a 6-axis radar, receive a learning roadmap, matched jobs and mock + technical interview coaching.
  • Solves fragmented prep — resume checking, planning, job search and interviews in four tools — with one dashboard and one auth session.
  • For students and placement seekers. Technically notable for 13+ agents centralised in server/agents.ts behind REST, with a local JSON file as the database.

02 · The Problem

The Problem

  • Career prep is scattered across ATS checkers, roadmap blogs, job boards and mock interviews that share no context.
  • Generic advice ignores the candidate's resume and target role.
  • No loop connects resume evidence → gaps → tasks → jobs → interview readiness.

03 · The Solution

The Solution

  • One workspace where the resume is the source of truth for downstream agents.
  • Modular agents (resume, quiz, recommendations, skill-gap, roadmap, courses, jobs, custom-job, interview, tech-interview, tips) over REST.
  • Dashboard summary + tabs: dashboard, resume, assessment, roadmap, jobs, interview, tech_interview, progress.

07 · Technical Implementation

Technical Implementation

  • React 19, Vite 6, Tailwind 4, recharts, lucide-react, motion; SEO wired to Render URL.

  • Gemini 2.5 Flash only; no embeddings/vector libs.
  • npm run build + npm start serves dist/ from Express on Render.

10 · Challenges & Decisions

Challenges & Decisions

  • File JSON limits concurrency → narrow schema + dashboard aggregation → single-file persistence on Render.
  • Many agents, one model → centralised prompts in agents.ts → consistent behaviour.
  • Similar-named RAG prototype exists → describe only this deploy → no vector claims.

11 · Result

Result

  • Working: auth, ATS analysis, radar, roadmaps, courses, job matching, interviews, streaks, dashboard.
  • Live on Render with SEO docs.
  • Limits: no vector retrieval, no standalone builder.
