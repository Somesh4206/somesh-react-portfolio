Case Study 04

JeduAI Connect

Smart Learning and Language Empowerment

JeduAI Connect is a Flutter/Dart multilingual learning platform for VSB Engineering College: student/staff/admin portals, Firebase auth, Gemini 2.5 Flash plus Groq/HuggingFace translation, online classes with video rooms, AI assessments and tutor. Live at jeduai-connect.netlify.app. AI attendance is not proven (mock values); Supabase URL is a placeholder.

01 · Overview

Overview

  • Role-based dashboards, online classes with meeting rooms, AI assessments, AI tutor and 100+-language translation.
  • Solves language/access barriers: same material across languages, roles and formats.
  • For VSB learners and faculty; web-deployed via Netlify.
  • GetX services/controllers across 100+ Dart files with parallel AI providers.

02 · The Problem

The Problem

  • Content, assessments and live classes rarely share one role-aware system.
  • Single-language material blocks understanding.
  • Teachers and admins need authoring and oversight — usually separate tools.

03 · The Solution

The Solution

  • Role routing (students/staff/admins collections → dashboards) with seeded admin.
  • OnlineClass model + service (SharedPreferences + seed) + video rooms + Supabase scaffolding.
  • Translation stack per task + AI generator, tutor, recommendations, planner, analytics, gamification.

06 · Core Features

Core Features

  • Role portals (16 student, 6 staff, 11 admin views).
  • Firebase auth with admin seed.
  • Online classes with schedule, links, enrolment and video rooms.
  • Multilingual + video translation pipelines.
  • AI assessments + tutor with recommendations.
  • Analytics, gamification, parent portal, messaging.

07 · Technical Implementation

Technical Implementation

  • Flutter/Dart + GetX + Material; 100+ files.
  • Gemini 2.5 Flash REST + Groq + HuggingFace per task.
  • Firestore + Auth + firebase_options; supabase_flutter unconfigured.
  • video/chewie/audio/tts/file/image pickers.
  • Netlify config for live web; Python backend/ scaffold present.

08 · My Contribution

My Contribution

  • GetX architecture across three role portals.
  • Assessment generator, tutor, multi-provider translation.
  • Class model/service, Firebase auth/data, local persistence.
  • Netlify web configuration.

09 · Tech Stack

Tech Stack

  • App: Flutter · Dart · GetX.
  • Data: Firebase Auth · Firestore · SharedPreferences.
  • AI: Gemini 2.5 Flash · Groq · HuggingFace.
  • Media: video_player · chewie · tts.
  • Deploy: Netlify.

10 · Challenges & Decisions

Challenges & Decisions

  • Many tasks/providers → per-task services behind shared views.
  • Three roles → Firestore collections + GetX routing.
  • Attendance honesty → report mocks/formula only, no face-recognition claims.

11 · Result

Result

  • Role auth + dashboards, classes with video rooms, translation, assessments + tutor, engagement services.
  • Live on Netlify (v1.0.2+3). Limits: no verified AI attendance; Supabase unconfigured.
